# Desa Kurniabakti

Website profil Desa Kurniabakti menggunakan HTML5, CSS3, JavaScript vanilla, Font Awesome, Google Fonts, dan Leaflet.js.

## Menjalankan

Buka `index.html` langsung di browser atau gunakan ekstensi Live Server di VS Code. Peta membutuhkan koneksi internet untuk memuat tile OpenStreetMap dan Leaflet.js.

## Kustomisasi

- Halaman utama ada di [index.html](index.html), sedangkan detail potensi memakai parameter URL pada [detail-potensi.html](detail-potensi.html): `tahu-tempe`, `pertanian-tanaman-pangan`, dan `perdagangan-ciawi`.
- Styling utama ada di [css/style.css](css/style.css) dan styling detail di [css/detail.css](css/detail.css).
- Ganti blok placeholder pemandangan di `index.html` dan visual kartu di CSS dengan foto desa asli.
- Perbarui alamat, nomor telepon, email, serta tautan media sosial pada bagian Kontak.
- Koordinat peta saat ini: `-7.15278, 108.13944`.
